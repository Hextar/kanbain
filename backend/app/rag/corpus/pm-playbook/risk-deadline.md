# Risk, dependencies, and deadlines

Name the risks that would stop the plan: missing access, unknown vendors, compliance, single-person bottlenecks.

Hard deadlines require a critical path and a cut list. Nice-to-have deadlines still get milestones but may slip the last slice. Ongoing work still needs a first milestone so the board is not infinite.

Assign work only to people named on the team. Empty team means unassigned cards, not invented teammates.

When load exceeds capacity before the deadline, say so in the plan instead of pretending the calendar will stretch.
